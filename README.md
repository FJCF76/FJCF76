## What is here

**[ai-digital-operations-lab](https://github.com/FJCF76/ai-digital-operations-lab)**
Practical experiments on how AI changes the way digital initiatives get executed and
scaled. Exploratory by design.

**[Webfiable](https://github.com/webfiable/Webfiable-Info)**
A monitoring plugin that reports on a site's health and security posture. This one
has users and a subscription behind it.

**[PromptingPress](https://github.com/FJCF76/PromptingPress)**
A WordPress theme built as a clean component framework, designed to be edited by AI
rather than by hand.

**[MarkupPM](https://github.com/FJCF76/MarkupPM)**
A desktop project manager that uses plain Markdown files as its data source, so the
data stays readable and version-controlled outside the tool.
